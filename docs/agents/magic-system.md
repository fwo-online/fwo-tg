# Система магий

Каталог заклинаний магов и жрецов (круги 1–7), статус реализации в кодовой базе и особенности механики.

> 💡 **План редизайна**: Специализации по веткам и целенаправленное изучение магий описаны в [`docs/specs/magic-branches-plan.md`](../specs/magic-branches-plan.md).

## Архитектура и файлы

| Слой / Компонент | Путь | Назначение |
|---|---|---|
| Конструкторы заклинаний | `server/arena/Constuructors/` | `MagicConstructor`, `CommonMagicConstructor`, `DmgMagicConstructor`, `AoeDmgMagicConstructor`, `LongMagicConstructor`, `LongDmgMagicConstructor` |
| Реализации заклинаний | `server/arena/magics/` | Отдельные файлы для каждого заклинания, экспорт через `index.ts` |
| Сервис магии | `server/arena/MagicService.ts` | Логика изучения (`learnMagic`), получение списков доступных магий |
| Порядок ходов (стадии) | `server/arena/config.ts` | Массив `stages` (определяет очередность исполнения действий в раунде) |
| HTTP API | `server/server/magic.ts` | Роуты `GET /magic`, `POST /magic/:lvl`, `GET /magic/available`, `GET /magic/:id` |
| Клиентский UI | `client/src/routes/(app)/character/magics/` | Просмотр изученных заклинаний и покупка случайной магии круга |

## Статус реализации заклинаний

Всего по дизайн-документу: **73 заклинания** (круги 1–7 базовые + круг 8 для улучшенных подклассов).
- **Реализовано**: 38 позиций (37 файлов, т.к. `lightHeal` общий для мага и жреца) — полностью покрыты круги 1–4, плюс 1 магия из 5-го круга.
- **Не реализовано**: 35 магий (7 из 5-го круга, все 7 из 6-го круга, все 7 из 7-го круга, все 14 из 8-го круга).

## Текущая механика изучения заклинаний

1. Игрок выбирает круг магии на клиенте.
2. `MagicService.learnMagic(character, lvl)`:
   - Проверяет требования к уровню персонажа (`canLearnMagic(character.lvl, lvl)`).
   - Формирует пул доступных магий данного круга для класса персонажа (`profList.includes(prof)`).
   - Выбирает **случайное заклинание** из пула: `magicsToLearn[MiscService.randInt(0, magicsToLearn.length)]`.
   - Списывает очки `bonus` (стоимость зависит от круга: `getLearnMagicCost(lvl)`).
   - Проверяет шанс успеха (по умолчанию 60% из `config.magic.learnChance`).
   - При успехе увеличивает уровень заклинания у персонажа вплоть до максимального (`MAX_MAGIC_LVL = 3`).
