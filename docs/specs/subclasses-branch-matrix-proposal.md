## 1. Концепция: Подклассы от веток, а не от базовых классов

В оригинальной FWO подклассы формировались простой комбинацией двух базовых классов (`w+l` = Ассасин, `m+w` = Тамплиер).  
Однако при наличии **12 глубоких веток специализации** эта система становится гораздо интереснее и осмысленнее:

> **Истинный подкласс персонажа определяется комбинацией двух выбранных веток специализации (Ветка 1 + Ветка 2).**

### Преимущества подхода:
1. **Логичность и ролевой отыгрыш**:
   - Не просто «Воин + Лучник», а конкретно **«Дуэлянт + Снайпер» = Ассасин** (смертоносные критические удары и скрытное фехтование).
   - А если Воин взял другую ветку Лучника — например, **«Оплот + Шквал»**, то это не Ассасин, а **Рыцарь** (тяжелый латник с щитом, стреляющий залпами по толпе).
2. **Сохранение всех 16 классических классов**:
   - Все 16 исторических названий FWO (Варвар, Ассасин, Элементалист, Аббат, Рыцарь, Снайпер, Друид, Монах, Тамплиер, Рейнджер, Архимаг, Хаотик, Инквизитор, Назгул, Отшельник, Епископ) находят своё естественное воплощение в парах веток.
3. **Огромная глубина билдов**:
   - Из 12 веток (по 3 на класс) формируется ровно **66 уникальных комбинаций** (12 внутриклассовых чистых архетипов + 54 гибридных подкласса).

## 5. Способности и заклинания 8-го уровня веток (Строго из старого реестра FWO)

### 5.1. Принцип: Заклинания 8-го уровня в каждой ветке — из старого реестра
Каждая из 12 веток специализации на вершине своего развития (8-й уровень / 8-й круг) открывает **заклинания и способности строго из оригинального реестра подклассов FWO**.

Никаких искусственных выдумок:
- 14 заклинаний 8-го круга полностью распределены между 6 магическими ветками.
- Классические активные умения и пассивки подклассов распределены между 6 физическими ветками воина и лучника.
- Персонаж с двумя ветками на 8 уровне получает доступ к заклинаниям/умениям 8 уровня **обеих своих веток**!

### 5.4. Синергия 2 веток: Как персонаж получает свои истинные способности

Когда персонаж прокачивает свои 2 ветки до 8 уровня, он объединяет арсенал 8-го уровня из **обеих веток**:

1. **Канонические подклассы FWO собирают свой аутентичный арсенал**:
   - **Архимаг** (`elements + arcana`): получает `Ледяной шторм`, `Ярость`, `Мозговую атаку`, `Подмену`.
   - **Хаотик** (`darkness + inquisition`): получает `Апокалипсис`, `Армагеддон`, `Кровавую ауру`, `Слабость`.
   - **Епископ** (`holy + protection`): получает `Святость`, `Святую защиту`, `Жажду крови`, `Ураганный ветер`.
   - **Рыцарь** (`guardian + barrage`): получает `Стену щитов`, `Мультитаргет (maxtarg=2)`, `Кровавый выстрел`.
   - **Снайпер** (`marksman + barrage`): получает `Меткость`, `Меткий выстрел`, `Мультитаргет`.
   - **Ассасин** (`duelist + marksman`): получает `Оглушающий удар`, `Отравление оружия`, `Меткость`, `Фатальный выстрел`.
   - **Рейнджер** (`scout + arcana`): получает `Двойное уклонение`, `Мозговую атаку`, `Подмену`.
   - **Назгул** (`marksman + inquisition`): получает `Меткий выстрел`, `Высасывание жизни`, `Апокалипсис`, `Слабость`.
   - **Аббат** (`guardian + holy`): получает `Стену щитов`, `Святость`, `Святую защиту`.
   - **Тамплиер** (`guardian + arcana`): получает `Стену щитов`, `Мозговую атаку`, `Клонирование`, `Подмену`.

2. **Новые гибриды (остальные 50 комбинаций)**:
   - Автоматически получают гармоничные заклинания и способности 8-го уровня из старого реестра, соответствующие их 2 веткам!
   - Например, *Магический дуэлянт* (`duelist + elements`): получает `Оглушающий удар`, `Отравление оружия`, `Ледяной шторм` и `Ярость`!
   - *Тёмный рыцарь* (`guardian + darkness`): получает `Стену щитов`, `Армагеддон` и `Кровавую ауру`!

### 5.5. Итог
- **100% старого реестра заклинаний 8-го круга (все 14)** бережно сохранено и нашло своё логичное место в магических ветках.
- **100% старых умений и пассивок подклассов** распределены по физическим веткам.
- Никакого дублирования или забытых заклинаний — каждый скилл старого реестра востребован и масштабируется на все 66 комбинаций!

## 6. Программная реализация в `@fwo/shared`

Вспомогательная функция определения подкласса:
```typescript
import type { BranchId } from './branches';

export function getSubclass(b1: BranchId, b2: BranchId): SubclassMeta {
  const pairKey = [b1, b2].sort().join('+');
  return SUBCLASS_MAP[pairKey] ?? DEFAULT_SUBCLASS;
}
```
Благодаря сортировке ключа `[b1, b2].sort()` порядок выбора веток не имеет значения: игрок может начать со Снайпера и взять Дуэлянта, либо начать с Дуэлянта и взять Снайпера — результат всегда гармоничен: **Ассасин**!
