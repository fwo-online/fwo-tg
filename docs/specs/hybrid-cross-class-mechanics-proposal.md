# Proposal: Кросс-архетипные гибриды, свитки и ресурсная модель (Мана vs Энергия)

> Статус: **Proposal (На согласовании)**  
> Связанные документы: [`docs/specs/subclasses-branch-matrix-proposal.md`](./subclasses-branch-matrix-proposal.md), [`docs/agents/warrior-archer-skills.md`](../agents/warrior-archer-skills.md), [`docs/agents/magic-system.md`](../agents/magic-system.md)

## 1. Контекст: Базовое разделение ресурсов в FWO

В FWO изначально заложено **строгое разделение ресурсов по базовым архетипам**:
- Физические классы (Воин `w`, Лучник `l`) обладают исключительно **⚡ Энергией (Energy)**. Маны у них нет (Mana = 0).
- Магические классы (Маг `m`, Жрец `p`) обладают исключительно **💧 Маной (Mana)**. Энергии у них нет (Energy = 0).

### В чём суть этого Proposal:
При переходе на систему, где каждому персонажу даётся возможность **изучать две ветки специализации**:
> Что происходит, когда персонаж в качестве **второй ветки** выбирает школу из чужого архетипа?  
> (Например, Воин берет ветку Мага/Жреца, или Маг берет ветку Воина/Лучника).

**Ключевой принцип:**
Второй ресурс **НЕ ПОЯВЛЯЕТСЯ**. Воин не получает ману, а маг не получает энергию. Вместо этого вступает в силу специальная кросс-архетипная механика **Свитков** и **Боевых уловок**.

## 2. Физик берёт магическую ветку: «Не настоящий маг» (Свитки / Руны / Артефакты)

Если персонаж с базовым классом **Воин (`w`)** или **Лучник (`l`)** выбирает в качестве второй ветки магическую школу (Стихии, Тьма, Аркана, Свет, Опека, Инквизиция):

```
       ┌────────────────────────────────────────────────────────────┐
       │   Воин / Лучник + Магическая ветка (Артефакты / Свитки)   │
       │                                                            │
       │   • Маны нет (0)                                           │
       │   • Прокачка магии выше 1-го уровня заблокирована          │
       │   • Кнопка «Изучить» → «Получить» (артефакт / свиток)      │
       │   • Заряд: 1/1 на КАЖДЫЙ спелл (восстанавливается к бою) │
       │   • На 8 ранге: легендарный ультимативный артефакт (1 зар.)│
       └────────────────────────────────────────────────────────────┘
```

### 2.1. Механика артефактов и зарядов
1. **Восстанавливаемый боевой заряд (не расходник за золото)**:
   - Игроку **не нужно** постоянно покупать бумажные свитки в магазине за золото после каждого раунда.
   - Персонаж один раз нажимает **«Получить»** в дереве ветки — и получает постоянный предмет в свой слот способностей.
   - В начале каждого боя у каждого полученного заклинания есть **ровно 1 заряд (1/1)**.
2. **Один заряд на спелл (1 charge per spell)**:
   - Если воин открыл в ветке 3 заклинания (например, `Огненная стрела`, `Ледяной щит` и `Молния`), у него есть **по 1 заряду на каждое из них**!
   - В течение боя он может разыграть каждое заклинание ровно по 1 разу (без затрат маны).
3. **Атмосферные формы предметов (по школам)**:
   - Заклинание оформляется визуально не только как бумажный свиток, но и в зависимости от школы:
     - ⚡ **Стихии**: *Стихийные руны / Кристаллы стихий* (воин раскалывает огненный кристалл).
     - ✨ **Свет**: *Освящённые реликвии / Молитвенные медальоны*.
     - 💀 **Тьма**: *Проклятые талисманы / Сосуды с прахом*.
     - 🔮 **Аркана**: *Запечатанные древние свитки*.
4. **8-й ранг ветки (Легендарный артефакт)**:
   - Достигнув 8-го ранга магии, воин получает **легендарный артефакт 8-го круга** (например, руну `Ледяного шторма` или печать `Святости`).
   - Применяется также 1 раз за бой как грандиозный тактический ультимейт!

## 3. Маг/Жрец берёт физическую ветку: «Не настоящий атлет» (Боевые уловки и гаджеты)

Симметричная механика работает в обратную сторону. Если персонаж с базовым классом **Маг (`m`)** или **Жрец (`p`)** берёт вторую ветку физического архетипа (Оплот, Ярость, Дуэлянт, Снайпер, Шквал, Следопыт):

```
       ┌────────────────────────────────────────────────────────────┐
       │   Маг / Жрец + Физическая ветка (Боевые уловки / Гаджеты) │
       │                                                            │
       │   • Энергии нет (0)                                        │
       │   • Прокачка физ. умений выше 1-го уровня заблокирована    │
       │   • Кнопка «Изучить» → «Получить» (боевой приём / уловка)  │
       │   • Заряд: 1/1 на КАЖДОЕ умение (восстанавливается к бою) │
       │   • На 8 ранге: ультимативный тактический манёвр (1 зар.)  │
       └────────────────────────────────────────────────────────────┘
```

### 3.1. Механика боевых уловок и приёмов
1. **Восстанавливаемый заряд уловки**:
   - Маг или жрец не обладает атлетической выносливостью воина, чтобы крутить приёмы каждые 2 раунда.
   - Но он осваивает **тактический приём / гаджет / военную хитрость**, готовый к применению в каждом бою (1/1).
2. **Один заряд на каждое физическое умение**:
   - Каждое освоенное физ. умение ветки можно применить ровно **1 раз за бой без затрат энергии**.
   - Примеры боевых уловок:
     - 🛡️ *Оплот*: экстренный глухой блок щитом/посохом.
     - 🗡️ *Дуэлянт*: удар скрытым стилетом / подсечка.
     - 🏃 *Следопыт*: дымовая шашка / тактический перекат от стрелы.
     - 🎯 *Снайпер*: выстрел из спрятанного мини-самострела.
3. **8-й ранг физической ветки для кастера**:
   - Открывает высший физический прием 8-го ранга (например, уловку `Стена щитов` или `Оглушающий удар`) на 1 решающий заряд за бой!

## 4. Сравнительная матрица развития веток

| Параметр | Родная ветка (Свой архетип) | Кросс-ветка (Чужой архетип) |
|---|---|---|
| **Ресурс** | Расходует Энергию (физик) / Ману (маг) | **Бесплатно** (без маны / без энергии) |
| **Уровень умения/магии** | Полная прокачка (1 → 2 → 3 ... 7) | **Строго 1-й уровень** |
| **Кнопка в интерфейсе** | **«Изучить» / «Улучшить»** | **«Получить»** (артефакт / уловка) |
| **Лимит в бою** | Пока хватает ресурса и кулдаунов | **1 заряд на каждый спелл/умение за бой** |
| **Тип предметов / формы** | Прямой навык / заклинание из книги | Руна, Свиток, Талисман / Уловка, Гаджет |
| **Истинная способность 8 ранга** | Полноценная способность / заклинание | Легендарный ультимативный заряд (1 раз за бой) |
| **Пассивные умения** | 100% эффективность | 50% базовая эффективность (1-й ранг) |

## 5. Преимущества для игры и UX

1. **Идеальная чистота UI для мобильного Telegram**:
   - Не нужно втискивать два ресурсных бара в узкий экран смартфона. У игрока всегда 1 понятная шкала (HP + Мана ИЛИ HP + Энергия).
2. **Абсолютный баланс без эксплойтов**:
   - Невозможна ситуация «тяжёлый латник с 2000 HP бесконечно хилится заклинаниями жреца».
   - Воин с веткой Света — это воин, у которого есть **один свиток спасительного исцеления** на бой. Это мощный тактический туз в рукаве, но не ломающий баланс кастер.
3. **Атмосфера и ролевой отыгрыш**:
   - «Не настоящий маг со свитком» и «Маг с спрятанным стилетом» — это живые, колоритные архетипы настольных и классических RPG, понятные любому игроку с полуслова.
