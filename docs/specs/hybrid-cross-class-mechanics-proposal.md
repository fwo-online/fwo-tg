# Proposal: Кросс-архетипные гибриды, свитки и ресурсная модель (Мана vs Энергия)

> Статус: **Proposal (На согласовании)**  
> Связанные документы: [`docs/specs/subclasses-branch-matrix-proposal.md`](./subclasses-branch-matrix-proposal.md), [`docs/agents/warrior-archer-skills.md`](../agents/warrior-archer-skills.md), [`docs/agents/magic-system.md`](../agents/magic-system.md)

## 1. Контекст: Базовое разделение ресурсов в FWO

В FWO изначально заложено **строгое разделение ресурсов по базовым архетипам**:
- Физические классы (Воин `w`, Лучник `l`) обладают исключительно **⚡ Энергией (Energy)**. Маны у них нет (Mana = 0).
- Магические классы (Маг `m`, Жрец `p`) обладают исключительно **💧 Маной (Mana)**. Энергии у них нет (Energy = 0).

### В чём суть этого Proposal:
При переходе на систему, где каждому персонажу даётся возможность **изучать две ветки специализации**:
> Что происходит, когда персонаж в качестве **второй ветки** выбирает школу из чужого архетипа?  
> (Например, Воин берет ветку Мага/Жреца, или Маг берет ветку Воина/Лучника).

**Ключевой принцип:**
Второй ресурс **НЕ ПОЯВЛЯЕТСЯ**. Воин не получает ману, а маг не получает энергию. Вместо этого вступает в силу специальная кросс-архетипная механика **Свитков** и **Боевых уловок**.

## 2. Физик берёт магическую ветку: «Не настоящий маг» (Свитки магии)

Если персонаж с базовым классом **Воин (`w`)** или **Лучник (`l`)** выбирает в качестве второй ветки магическую школу (Стихии, Тьма, Аркана, Свет, Опека, Инквизиция):

```
       ┌────────────────────────────────────────────────────────────┐
       │   Воин / Лучник + Магическая ветка (Свитки магии)         │
       │                                                            │
       │   • Маны нет (0)                                           │
       │   • Прокачка магии выше 1-го уровня заблокирована          │
       │   • Кнопка «Изучить» → «Получить» (свиток магии)          │
       │   • В бою: 1 использование за весь бой (расход заряда)    │
       └────────────────────────────────────────────────────────────┘
```

### 2.1. Механика свитков (Magic Scrolls)
1. **Нарратив**: Воин или лучник не обучался годами в академиях магии и не слышит эфирные потоки. Он «не настоящий маг». Однако он может носить в сумке зачарованный древний пергамент.
2. **Интерфейс изучения**:
   - В дереве ветки кнопка **«Изучить»** заменяется на **«Получить»** (визуально игрок получает свиток магии).
   - Заклинание можно получить только **1-го уровня** (глубокое улучшение заклинаний до 2–7 уровней заблокировано — для этого нужна врождённая мана).
3. **Использование в бою**:
   - В боевом меню воина появляется отдельная плашка **«📜 Свитки»**.
   - Использование свитка **не требует маны**.
   - Свиток можно применить **ровно 1 раз за весь бой**: в раунде персонаж ломает печать и читает формулу, после чего свиток сгорает (исчерпывает боевой заряд).
4. **Примеры в игре**:
   - *Тамплиер* (`Воин + Аркана`): Воин в латах держит в сумке свиток `Магического щита` или `Подмены` и применяет его в критический момент раунда.
   - *Элементалист* (`Воин + Стихии`): Берсерк разрывает свиток `Огненной стрелы` или `Ледяного щита`, один раз шокируя противника стихийным ударом.
   - *Друид* (`Лучник + Стихии`): Лучник раз в бой бросает свиток `Исцеления` или `Каменной кожи`.

## 3. Маг/Жрец берёт физическую ветку: «Не настоящий атлет» (Боевые уловки)

Симметричная механика работает в обратную сторону. Если персонаж с базовым классом **Маг (`m`)** или **Жрец (`p`)** берёт вторую ветку физического архетипа (Оплот, Ярость, Дуэлянт, Снайпер, Шквал, Следопыт):

```
       ┌────────────────────────────────────────────────────────────┐
       │   Маг / Жрец + Физическая ветка (Боевые уловки / Приёмы)   │
       │                                                            │
       │   • Энергии нет (0)                                        │
       │   • Прокачка физ. умений выше 1-го уровня заблокирована    │
       │   • Кнопка «Изучить» → «Получить» (боевой приём)          │
       │   • В бою: 1 использование за весь бой (тактический трюк)  │
       └────────────────────────────────────────────────────────────┘
```

### 3.1. Механика боевых уловок (Tactical Moves / Tricks)
1. **Нарратив**: Хрупкий маг или монах-жрец не обладает атлетизмом, дыхалкой и физической мускулатурой воина для бесконечных серий ударов и стоек. Он «не настоящий боец». Но он может застать врага врасплох одним заранее отточенным тактическим движением.
2. **Интерфейс изучения**:
   - В ветке умения кнопка **«Изучить»** заменяется на **«Получить»** (визуально персонаж осваивает разовый приём/уловку).
   - Умение доступно только **1-го уровня**.
3. **Использование в бою**:
   - В боевом меню мага появляется кнопка **«⚔️ Боевая уловка»** (или «Тактический приём»).
   - Применение **не требует энергии**.
   - Приём активируется **ровно 1 раз за бой**: например, внезапный парирующий блок (`guardian`), подножка с кинжалом (`duelist`), дымовая завеса (`scout`) или выстрел из спрятанного мини-арбалета (`marksman`).
4. **Примеры в игре**:
   - *Инквизитор* (`Жрец + Дуэлянт`): Жрец читает проповеди и кастует свет, но когда враг подходит в упор — внезапно проводит 1 раз за бой `Оглушающий удар` скрытым кинжалом.
   - *Рейнджер* (`Маг + Следопыт`): Маг использует разовую уловку `Двойное уклонение` / `Дымовая завеса`, чтобы избежать смертельного залпа стрел.

## 4. Сравнительная матрица развития веток

| Параметр | Родная ветка (Свой архетип) | Кросс-ветка (Чужой архетип) |
|---|---|---|
| **Ресурс** | Расходует Энергию (физик) / Ману (маг) | **Бесплатно** (без маны / без энергии) |
| **Уровень умения/магии** | Полная прокачка (1 → 2 → 3 ... 7) | **Строго 1-й уровень** |
| **Кнопка в интерфейсе** | **«Изучить» / «Улучшить»** | **«Получить»** (свиток / приём) |
| **Лимит в бою** | Пока хватает ресурса и кулдаунов | **Ровно 1 раз за бой** (1 заряд) |
| **Истинная способность 8 ранга** | Полноценная способность / спелл | Разовый легендарный свиток / ультимативный трюк |
| **Пассивные умения** | 100% эффективность | 50% базовая эффективность (1-й ранг) |

## 5. Преимущества для игры и UX

1. **Идеальная чистота UI для мобильного Telegram**:
   - Не нужно втискивать два ресурсных бара в узкий экран смартфона. У игрока всегда 1 понятная шкала (HP + Мана ИЛИ HP + Энергия).
2. **Абсолютный баланс без эксплойтов**:
   - Невозможна ситуация «тяжёлый латник с 2000 HP бесконечно хилится заклинаниями жреца».
   - Воин с веткой Света — это воин, у которого есть **один свиток спасительного исцеления** на бой. Это мощный тактический туз в рукаве, но не ломающий баланс кастер.
3. **Атмосфера и ролевой отыгрыш**:
   - «Не настоящий маг со свитком» и «Маг с спрятанным стилетом» — это живые, колоритные архетипы настольных и классических RPG, понятные любому игроку с полуслова.
