## 1. Концепция и синергия с атаками оружием

В каждой из 6 магических веток вводится ровно по **2 уникальных пассивных таланта** (всего 12).  
Пассивки спроектированы так, чтобы работать **не только для чистых кастеров, но и для гибридных классов (воинов и лучников со свитками/артефактами)**:

1. **Синергия с обычными атаками оружием (On-Hit проки)**:
   - Лучник или воин, выбравший магическую ветку, получает зачарование своих стрел и ударов (горение, мороз, яд, святой урон, сжигание маны).
   - Чистый маг или жрец при ударе оружием/посохом также активирует эти эффекты.
2. **Независимость от маны**:
   - Пассивки не требуют затрат маны или энергии — они работают пассивно или срабатывают по боевым триггерам (хукам).
3. **Восстановление способностей**:
   - Пассивки взаимодействуют с зарядами способностей (например, «Жатва душ» перезаряжает заклинания и свитки).

## 3. Архитектурная интеграция в движок боя

### 3.1. Хранение данных
Пассивные таланты хранятся в существующей структуре `character.passiveSkills`:
```typescript
character.passiveSkills: Record<string, number>; 
// пример: { ignition: 2, phaseShift: 1, soulHarvest: 3 }
```

### 3.2. Хуки боевого цикла (`server/arena/PlayerAffects`)
- `ignition`: хук `onDamageDealt` (проверка: урон огнем ИЛИ физ. атака оружием → наложение DoT `burn`).
- `frostBite`: хук `onDamageDealt` (проверка: урон холодом ИЛИ физ. атака оружием → наложение дебаффа `frostBite`).
- `soulHarvest`: хук `onKill` (проверка гибели врага → выбор 1 случайного заклинания школы тьмы с кулдауном/израсходованного свитка → сброс кулдауна / восстановление 1 заряда).
- `virulence`: хук `onDamageDealt` (проверка: кислота ИЛИ атака оружием → наложение DoT `poison`).
- `phaseShift`: хук `onBeforeDamageRecieve` (проверка: тип урона = магический → проверка шанса → полное поглощение урона).
- `mindClarity`: флаг `immuneToMadness = true`, `immuneToGlitch = true`, срез шанса срыва каста.
- `grace`: хук `onBeforeHeal` (крит-хил) + хук `onDamageDealt` (атака оружием → отхил союзника святостью).
- `divineIntervention`: хук `onBeforeDamageRecieve` (проверка `hp <= 0` или `< 20%` + проверка флага `usedOnce` → отхил + снятие дебаффов).
- `sacredArmor`: модификатор защитных аур + хук `onDamageDealt` (атака оружием → бафф блока).
- `spellReflect`: хук `onSpellTargeted` (проверка шанса → перенаправление цели заклинания на атакующего).
- `retribution`: хук `onDamageRecieved` (нанесение святого урона источнику атаки).
- `inquisitorSeal`: хук `onDamageDealt` (срез ресурса цели + шанс сайленса).

## 4. Итог

- 🎯 **Идеальная гибридность**: Пассивки делают выбор чужой магической ветки воином или лучником по-настоящему глубоким и полезным в каждом раунде боя.
- ⚖️ **Баланс**: Пассивки не требуют маны, не перегружают экран смартфона и дают яркий тактический почерк каждому из 66 подклассов.
