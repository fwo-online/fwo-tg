# Proposal: Пассивные таланты для магических школ (Маг и Жрец)

> Статус: **Proposal (На обсуждении)**  
> Связанные документы: [`docs/agents/magic-system.md`](../agents/magic-system.md), [`docs/specs/magic-branches-plan.md`](magic-branches-plan.md), [`docs/agents/warrior-archer-skills.md`](../agents/warrior-archer-skills.md)

---

## 1. Цели и мотивация

В текущей версии игры система магии включает 37 реализованных активных заклинаний, распределенных по 6 веткам специализации. Однако все доступные магу и жрецу способности — исключительно **активные заклинания**, требующие заказа действия на раунд и расходующие ману `mp`.

### Проблемы текущего подхода
1. **Отсутствие пассивной синергии**:
   - Маг огня просто кидает `fireBall`, не имея пассивных усилений горения или поджога.
   - Жрец света просто жмет `strongHeal`, не имея бонусов к крит-хилу или регенерации маны.
2. **Асимметрия с физическими классами**:
   - Воины и лучники получают смешанное дерево из активных ударов и пассивных боевых талантов (парирование, клив, метка, уклонение).
3. **Решение**:
   - Ввести в каждую из 6 магических веток по **2 уникальных пассивных таланта**, гармонично вписывающихся в дерево прокачки ветки.
   - Пассивные таланты не требуют нажатия кнопки в раунде — они работают непрерывно или активируются по триггерам боя (хукам).

## 2. Предлагаемый каталог пассивных талантов

### 2.1. Маг (`m`)

| Ветка | Пассивный талант | Код / ID | Механика и синергия | Ранги (1–3) |
|---|---|---|---|---|
| **⚡ Стихии (`elements`)** | **Воспламенение** | `ignition` | Заклинания огня (`fireBall`, `fireRain`) с шансом накладывают эффект горения: периодический урон огнем на 2 раунда. Синергия с взрывным стихийным уроном. | Шанс: `30% / 40% / 50%`<br>Урон: `20% / 30% / 40%` от урона спелла |
| **⚡ Стихии (`elements`)** | **Окоченение** | `frostBite` | Заклинания холода (`frostTouch`) охлаждают цель, снижая её физическую атаку и ловкость на 2 раунда (замедление реакции и промахи). | Срез атаки: `-10% / -18% / -25%`<br>Срез ловкости: `-10% / -18% / -25%` |
| **💀 Тьма (`darkness`)** | **Жатва душ** | `soulHarvest` | При гибели любого противника маг поглощает осколок его души, мгновенно восстанавливая ману и часть здоровья. | Мана: `+10% / +15% / +20%`<br>HP: `+5% / +10% / +15%` |
| **💀 Тьма (`darkness`)** | **Трупный яд** | `virulence` | Усиливает токсичность: весь периодический урон ядом (`poisonBreath`), кислотой (`acidSpittle`) и кровотечением увеличивается на процент. | Бонус к DoT: `+20% / +35% / +50%` |
| **🔮 Искажение (`arcana`)** | **Магический щит** | `manaShield` | Часть входящего физического урона поглощается за счет маны вместо здоровья (соотношение 1 MP поглощает 1.5 урона). Выключается, если мана исчерпана. | Поглощение: `15% / 25% / 35%` входящего физ. урона |
| **🔮 Искажение (`arcana`)** | **Ясность разума** | `mindClarity` | Непоколебимая концентрация: маг получает иммунитет к безумию (`madness`) и глюкам (`glitch`), а шанс срыва его заклинаний снижается. | Снижение срыва магии: `-15% / -25% / -35%` |

### 2.2. Жрец (`p`)

| Ветка | Пассивный талант | Код / ID | Механика и синергия | Ранги (1–3) |
|---|---|---|---|---|
| **✨ Свет (`holy`)** | **Благодать** | `grace` | Все лечащие заклинания жреца (`lightHeal`, `mediumHeal`, `strongHeal`) получают шанс критического удвоенного исцеления (x2.0 эффект). | Шанс крит-хила: `15% / 25% / 35%` |
| **✨ Свет (`holy`)** | **Медитация** | `meditation` | Глубокая молитва: в начале каждого раунда жрец пассивно восстанавливает фиксированное количество маны. | Восполнение: `+8 / +15 / +25` MP каждый раунд |
| **🛡️ Опека (`protection`)** | **Священная броня** | `sacredArmor` | Увеличивает силу всех наложенных жрецом защитных эффектов (ауры `smallAura`/`mediumAura`, `blessing`, `stoneSkin`, `magicWall`). | Бонус к защитным эффектам: `+15% / +25% / +35%` |
| **🛡️ Опека (`protection`)** | **Зеркальное отражение** | `spellReflect` | Священный барьер имеет шанс отразить направленное враждебное заклинание обратно в кастера (враг сам получает эффект своего заклинания). | Шанс отражения: `10% / 18% / 25%` |
| **⚖️ Инквизиция (`inquisition`)** | **Возмездие** | `retribution` | Аура праведного возмездия: любой противник, наносящий урон жрецу, получает процент святого отраженного урона. | Отражение урона: `10% / 20% / 30%` |
| **⚖️ Инквизиция (`inquisition`)** | **Печать праведника** | `sealOfPurity` | В начале каждого раунда с шансом автоматически развеивает 1 случайный отрицательный длительный эффект со жреца или союзника. | Шанс авто-диспела: `25% / 40% / 60%` |

## 3. Архитектурная интеграция

### 3.1. Хранение данных
- Пассивные таланты хранятся в существующем поле модели:
  ```typescript
  character.passiveSkills: Record<string, number>; // { ignition: 1, meditation: 2 }
  ```
- Каждое заклинание/пассивка в классе объявляет свои ветки:
  ```typescript
  // server/arena/passiveSkills/ignition.ts
  export default new Ignition({
    name: 'ignition',
    displayName: '🔥 Воспламенение',
    branches: ['elements'], // привязка к ветке Стихий
    ...
  });
  ```

### 3.2. Хуки боевого движка
Пассивки реализуются как наследники `PassiveSkillConstructor` и используют стандартные события `PlayerAffects`:
- `ignition` → хук `onDamageDealt` (проверка заклинания огня → наложение DoT `burn`).
- `frostBite` → хук `onDamageDealt` (проверка заклинания холода → дебафф атаки/ловкости).
- `soulHarvest` → хук `onKill` (гибель игрока в игре → пополнение MP и HP).
- `virulence` → хук `onDamageDealt` (увеличение урона периодических заклинаний).
- `manaShield` → хук `onBeforeDamageRecieve` (перехват урона с HP на `stats.mp`).
- `grace` → хук `onBeforeHeal` (расчет шанса критического исцеления).
- `meditation` → хук `onRoundStart` (пассивное пополнение MP).
- `retribution` → хук `onDamageRecieved` (нанесение святого урона атакующему).
- `sealOfPurity` → хук `onRoundStart` (поиск и снятие 1 дебаффа).

### 3.3. Визуализация в интерфейсе
- На странице `client/src/routes/(app)/character/magics/+page.svelte` в дереве ветки заклинания и пассивки выводятся вместе:
  - ⚡ **Активное заклинание**: указан круг (К1–К7), стоимость маны `12 MP`, тип действия.
  - 🛡️ **Пассивный талант**: бейдж `Пассивно`, описание триггера, нет расхода маны.
- Прокачка стоит стандартные очки бонусов 💡 (ранги 1, 2, 3), со 100% шансом и полным возвратом при сбросе.

## 4. Вопросы для обсуждения

1. **Баланс мана-щита (`manaShield`)**:
   - Стоит ли ограничивать максимальный урон, поглощаемый за один раунд (например, не более 50% текущей маны)?
2. **Отражение заклинаний (`spellReflect`)**:
   - Отражать только заклинания прямого урона (`fireBall`, `magicArrow`) или также дебаффы (`curse`, `silence`, `paralysis`)?
3. **Периодический DoT от огня (`ignition`)**:
   - Добавить новый эффект `burning` в `server/arena/effects/` по аналогии с `bleeding`.
